# 462: Doai Station

A first-person horror game set at an abandoned mountain station in Japan. A school project. Headphones, lights off.

**Download (Windows 10/11, 64-bit):** get `Setup.exe` from the [newest release](https://github.com/costoudesiason/462-game/releases/latest/download/Setup.exe) and run it. It downloads the game (3.3 GB), installs it where you choose, and puts a shortcut on your desktop. Run it again later to update.

If Windows says it protected your PC: **More info**, then **Run anyway** (the installer isn't code-signed).

No Mac version yet. This repository only holds the game's builds.
